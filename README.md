# Invito per il diciottesimo compleanno di Kevin Tobia

Un sito a tema **One Piece** per invitare amici e familiari al diciottesimo compleanno di Kevin Tobia.

L’invito si apre come una lettera dentro una busta, accompagnata da immagini e musica. Presenta le informazioni sulla festa ed è pensato per essere consultato anche da telefono.

Ogni invitato riceve un **link personale** con cui può confermare la partecipazione e segnalare eventuali allergie o intolleranze. Le risposte vengono salvate e rese disponibili all’organizzatore.

Kevin dispone di un **pannello riservato** per creare e gestire gli inviti, consultare le presenze confermate e stampare l’elenco dei partecipanti.
